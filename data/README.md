# 公共演示素材来源

GitHub仅保存public_demo_sources.json中的固定12项资产ID、官方URL和SHA256，不上传图片数据。执行python tools/prepare_demo_data.py获取，输出位于被Git忽略的data/public_demo目录。已有data/demo_manifest.json不会被覆盖。

素材与预览来自ambientCG官方CC0资源。查询为基础颜色贴图，候选为相同资产的材质球预览。它们不构成独立真实照片测试，也不等同于论文Trained或Unseen基准。许可：https://docs.ambientcg.com/license/ 。
